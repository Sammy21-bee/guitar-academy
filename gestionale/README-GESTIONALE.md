- Titolare: `demo-damiano`
- Admin: `demo-admin`

## Limiti importanti

Questa è una demo statica: non ha un server, un database o autenticazione reale. Le credenziali sono pubbliche; i dati creati restano nel localStorage del singolo browser e non si sincronizzano con Damiano o con altri dispositivi. Il backup scaricato contiene tutti i dati inseriti e va conservato privatamente.

Non inserire nomi, contatti, foto, dati sanitari o altri dati reali dei clienti. La versione condivisa del gestionale richiede prima autenticazione server-side e un database privato; non pubblicare file con dati clienti o PIN.
